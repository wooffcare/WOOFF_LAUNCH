# WOOFF_LAUNCH

Wooff Kids - Chocolate Toothpaste Coming Soon Teaser Website.

## Features
- **Cross-Platform Responsive Design**: Full-screen edge-to-edge desktop mode and dedicated mobile view that fits phones and tablets without shrinking.
- **Teaser Blur Effect**: Blurred product tube on the stone pedestal with chocolate chunks.
- **Loading Animation**: 12-spoke activity indicator clearly positioned above the product tube.
- **Text Typing Effect**: Smooth typewriter animation for *"Better oral care for kids?"* with stationary search icon.
- **Asset Optimization**: High-resolution image assets and clean vector icons.

## Quick Start
Open `index.html` in your web browser, or run a local server:
```bash
python3 -m http.server 8000
```
Then visit `http://localhost:8000`.
